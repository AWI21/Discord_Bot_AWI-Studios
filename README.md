# 🐺 Wolfy Bot
> A high-performance, feature-rich Discord bot built with **Discord.js v14**, **Turso (SQLite Cloud)**, and **Slash Commands**.

## 📋 Features

### 📈 Engagement & Fun
| Feature | Slash Command | Description |
| :--- | :--- | :--- |
| **Leveling** | `/rank` | Beautiful Canvas-based rank cards. |
| **Leaderboard** | `/leaderboard` | View top members by XP/Level. |
| **Birthdays** | `/remember-birthday` | Daily checks with 24h special roles. |
| **Vouching** | `/vouch` | Reputation system for community trust. |
| **Achievements**| `/achievements` | Role rewards for message milestones. |

### 🛡️ Moderation & Utility
| Feature | Slash Command | Description |
| :--- | :--- | :--- |
| **Moderation** | `/ban`, `/kick`, `/mute` | Complete suite of admin tools. |
| **Tickets** | `/ticket panel` | Button-based support system. |
| **Custom Cmds**| `/customcmd` | Create commands with **Role Restrictions**. |
| **Embeds** | `/embed` | Interactive rich embed builder. |
| **Socials** | `Auto` | YouTube & Twitch notifications. |
